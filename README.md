### Open-source QA tools

| Project | What it does |
|---|---|
| [test-management-qa](https://github.com/imsrj57/test-management-qa) | Single-file browser tool for manual test runs, retests, regression and screenshot evidence, with Excel/ZIP reports. No server, no login, no licence fee. |
| [playwright-requests](https://github.com/imsrj57/playwright-requests) | Plug-and-play pytest framework for UI (Playwright) and API (requests) testing, with a self-contained HTML report built from Allure JSON for machines where the Allure CLI is blocked. |
| [playwright-mcp-ai-testing](https://github.com/imsrj57/playwright-mcp-ai-testing) | Playwright tests drafted by an AI agent through the Playwright MCP server, reviewed by hand, with a review log of what changed. |
| [llm-response-testing](https://github.com/imsrj57/llm-response-testing) | Pytest suite that tests an LLM support bot for accuracy, hallucination, prompt injection, consistency and JSON output. |

These are personal projects, built in my own time between 2024 and 2025 and published here in November 2026. They aren't affiliated with any employer.
